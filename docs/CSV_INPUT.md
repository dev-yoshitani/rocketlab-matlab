# CSVで機体を入力する

部材の寸法・材料と、全部品の質量・位置を2つのCSVに分けて入力する。
作成する構造モデルは、接合部の柔軟性を考慮しない等方性の連続円管梁である。
部材境界でも変位と回転は連続する。回転剛性0のヒンジを置くモデルではない。
カプラなどの回転ばねを設定する場合は、既存の機体JSONを使う。

## 操作

1. `data/templates/members.csv`と`parts.csv`を、作成した`data/local`フォルダまたはリポジトリ外へコピーする。
2. Excelなどで編集し、**CSV UTF-8（コンマ区切り）**で保存する。列名と列の順番は変えない。
3. アプリの「機体の入力」→「CSVから入力」で、2つのCSVを選ぶ。
4. 機体ID、改訂、全長、CSVの位置基準を入力し、「CSVを読込・照合」を押す。
5. 部品表の総質量と重心を確認する。任意の基準質量・基準重心を入力した場合は差分も表示する。
6. 「機体JSONと照合を保存」で、新しいフォルダに`vehicle.json`と`input_check.json`を保存する。
7. 構造計算する場合は「荷重JSONを選ぶ」で、この機体に対応する荷重を選び、「2 構造を計算」を押す。

取込後に以前の荷重や結果を流用しない。
読込が失敗した場合やファイル選択を取り消した場合は、採用済みの入力を保持する。
部材を編集すると、以前の計算結果とCSV照合記録は無効になる。質量・重心を確認するには部品表も見直して再取込する。

架空の記入例は`data/demo/members.csv`と`parts.csv`である。
全長1000 mm、位置基準「ノーズから」で、総質量4 kg、重心550 mmになる。
部材表には円管だけを記載し、部品表には円管を含む全機の質量を重複なく記載する。
部材の計算質量を部品表の総質量へ加算しない。

## 部材表

| 列 | 意味・単位 |
|---|---|
| id | 重複しない部材ID |
| s0_mm, s1_mm | 選択した原点からの開始・終了位置 [mm]。s0 < s1 |
| diameter_mm, thickness_mm | 外径・半径方向の板厚 [mm] |
| E_GPa, nu | 等方性ヤング率 [GPa]・ポアソン比 |
| density_kg_m3 | 密度 [kg/m³] |
| tension_MPa, compression_MPa, shear_MPa | 引張・圧縮・せん断の許容値 [MPa] |
| deflection_mm | 相対変位の許容値 [mm] |
| strengthFactor | 要求安全率。1以上 |
| source | 図面改訂・測定記録・物性値の出典など |

全ての列が必要である。密度、各許容値、要求安全率は、分からなければセルを空欄にする。
欠損を0、`NaN`、`Inf`、推測した材料値で埋めない。
形状・E・nu・ID・出典は必須であり、欠損時は読込を止める。
部材はノーズから後端まで隙間・重複なく覆う必要がある。行の並び順は自動で整列する。

## 部品表と位置基準

| 列 | 意味・単位 |
|---|---|
| id | 重複しない部品ID |
| position_mm | 選択した原点からの部品重心位置 [mm] |
| mass_kg | 部品質量 [kg]。0以上、総質量は正 |
| source | 質量・位置の出典 |

両方のCSVと任意の基準重心には、同じ位置基準を使う。
「後端から」の場合、部品位置は `s = 全長 − 元位置`、部材区間は `[全長 − s1, 全長 − s0]` へ変換する。
内部のSI座標と結果の重心位置は、常にノーズから後端へ増加する。
これは軸方向位置だけの変換であり、3次元CADの座標・力・慣性テンソルは取り込まない。

基準との差は「集計値 − 基準値」である。重心は両方をノーズ基準にして比較する。
測定誤差や許容差を指定していないため、自動の合否判定は行わない。
部品表の漏れ、組立状態の相違、構造モデルと実物の対応は利用者が確認する。

## MATLABから使う

```matlab
startup_project
options = struct('id', 'my-vehicle', 'revision', 'R1', ...
    'length_mm', 1000, 'origin', 'nose');
% 任意: options.referenceMass_kg = 4; options.referenceCG_mm = 550;
[vehicle, audit] = rocketlab.import_vehicle_csv( ...
    'data/demo/members.csv', 'data/demo/parts.csv', options);
folder = rocketlab.save_vehicle_input(vehicle, 'outputs');
```

`origin`は`nose`または`tail`を必ず指定する。基準値の省略には未指定または`NaN`を使う。
既存の機体JSON形式（schemaVersion=1）は変えない。取込由来の機体には任意フィールド`csvImport`を付ける。
このフィールドには部品表、集計、入力ファイル名・SHA-256・単位・原点・機体ハッシュを保存する。
構成との一致を確認できない記録は、検証・保存時に取り除く。
構造レポートにも、その構成に対応する記録だけを`input_check.json`として保存する。

今回の取込は仮定付き入力であり、実機の妥当性確認や全機の安全性の評価ではない。
部品表から飛行荷重、慣性テンソル、推進薬履歴を自動生成しない。
利用者のCSV、生成したJSON、実機のスクリーンショットを公開リポジトリへ追加しない。
